## 📖 About

Mineshaft Finder predicts abandoned mineshaft locations from the world seed, rendering chest ESP and corridor outlines through terrain.

---

## ✨ Features
<a name="features"></a>

- **Corridor Rendering** — mineshaft tunnels drawn through stone.
- **Chest ESP** — minecart chests highlighted through walls.
- **Spider Spawner Rooms** — specific spawner corridors marked.
- **Distance Sort** — nearest shaft first in HUD.
- **Toggle Key** — quick on/off.
- **Loot Preview** — estimated chest loot table shown.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
